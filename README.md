This is a fun, colorful, and interactive web application designed to help children practice basic arithmetic operations. The app uses a kid-friendly interface and provides instant audio feedback to make learning engaging and effective.

# Features

Simple Arithmetic Practice: Focuses on fundamental operations: addition, subtraction, multiplication, and division.

Multiple Choice Questions: Each problem is presented with multiple choice answers, suitable for young learners.

Colorful & Kid-Friendly UI: The application features a bright, engaging, and easy-to-navigate design.

Operation Selection: Users can easily choose which arithmetic operation they want to practice via dedicated buttons.

Audio Feedback: Instant sound indication when a mistake is made, helping children quickly identify and correct errors.

# Technologies Used

This application is built using standard web technologies:

HTML5: For the core structure and content.

CSS3: For styling, layout, and creating the colorful, responsive UI.

JavaScript (ES6+): For the application logic, generating math problems, handling user input, managing scores, and providing audio feedback.

# Getting Started
To run this application locally, follow these simple steps:

Install Live server extension

Run this at root folder - python -m http.server 8000

Then open http://localhost:8000/index.html in your browser.
